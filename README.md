# 🌐 Rupinder Kaur — Portfolio

A modern, responsive personal portfolio website built with vanilla **HTML, CSS, and JavaScript** — no frameworks, no build step. Featuring a dark/light theme, smooth scroll animations, a typing effect, and a fully responsive layout.

🔗 **Live site:** https://roop454.github.io/portfolio/

## ✨ Features

- 🌗 **Dark / Light mode** with system-preference detection and persistence
- 📱 **Fully responsive** — looks great on mobile, tablet, and desktop
- 🎬 Scroll-reveal animations, animated typing headline, and count-up stats
- ⚡ **Zero dependencies** — pure HTML/CSS/JS, instant load
- ♿ Respects `prefers-reduced-motion` for accessibility

## 🛠️ Tech Stack

`HTML5` · `CSS3` (custom properties, grid, flexbox) · `Vanilla JavaScript`

## 🚀 Run Locally

```bash
git clone https://github.com/Roop454/portfolio.git
cd portfolio
# open index.html in your browser, or serve it:
python -m http.server 8000
```
